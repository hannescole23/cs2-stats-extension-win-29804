## About CS2 Stats for Steam Profiles

CS2 Stats for Steam Profiles is a Chrome extension that adds Counter-Strike 2 context to Steam profile pages. It is designed for users who want to check competitive-related information without moving between multiple services or tabs.

The extension combines data from Steam, Leetify, and Faceit into a right-side profile panel. It is built on Manifest V3 and is intended to work with minimal setup, while still exposing useful details such as XP, rank, friend code, commendations, match history, and KD calculations.

---

## Features

- Shows CS2 stats while browsing Steam profiles
- Collects Steam, Leetify, and Faceit data in one panel
- Uses a right-side profile UI for quick reading
- Includes XP, rank, friend code, and commendation details
- Pulls match history and calculates KD
- Built as a Manifest V3 Chrome extension
- Supports Faceit API key usage through a proxy flow
- Designed for zero-setup use after installation
